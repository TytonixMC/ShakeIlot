# SHAKE ILOT 1.5 BETA

Браузерная игра «змейка» на HTML, CSS и JavaScript.

## Запуск локально
Открой `index.html` в современном браузере.

## Публикация через GitHub Pages
1. Создай новый репозиторий на GitHub.
2. Загрузи в корень репозитория файлы `index.html`, `style.css`, `script.js` и `README.md`.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`, затем нажми **Save**.
6. Подожди завершения публикации — GitHub покажет адрес сайта в разделе Pages.

## Важно
Аккаунты, прогресс, монеты и настройки хранятся в `localStorage` браузера на конкретном устройстве. Это не общая онлайн-база данных: данные не синхронизируются между устройствами. Пароли в этой демонстрационной версии также хранятся локально в браузере, поэтому не используй настоящие или важные пароли.
