# SHAKE ILOT 1.9 KITSUNE UPDATE

Игра разделена на три обычных веб-файла:
- `index.html` — структура страницы
- `style.css` — стили и оформление
- `script.js` — логика игры

## Запуск
Открой `index.html` в современном браузере.

## Публикация через GitHub Pages
1. Создай репозиторий на GitHub.
2. Загрузи в корень репозитория все три файла.
3. Открой **Settings → Pages**.
4. Выбери **Deploy from a branch**, ветку `main`, папку `/ (root)` и нажми **Save**.
5. После публикации открой выданный GitHub Pages адрес.

## Примечание
Аккаунты и прогресс хранятся в `localStorage` браузера. Это локальное демо-хранилище, а не защищённая серверная авторизация.
