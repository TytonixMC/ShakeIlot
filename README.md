# SHAKE ILOT — GitHub Pages

## Файлы проекта
- `index.html` — страница игры
- `style.css` — оформление и адаптивный дизайн
- `script.js` — игровая логика

## Запуск локально
Откройте `index.html` в современном браузере.

## Публикация на GitHub Pages
1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите в корень репозитория все четыре файла.
3. Откройте **Settings → Pages**.
4. В разделе Build and deployment выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. После публикации сайт будет доступен по адресу GitHub Pages вашего репозитория.

> Прогресс этой версии хранится в localStorage браузера. Это удобно для простой статической игры, но не обеспечивает защищённую серверную авторизацию или защиту админских функций.
