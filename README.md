# SHAKE ILOT 1.0 BETA

Браузерная игра «Змейка» на HTML, CSS и JavaScript.

## Запуск локально
Откройте `index.html` в браузере. Для разработки можно использовать Live Server.

## Публикация на GitHub Pages
1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите в корень репозитория файлы `index.html`, `style.css` и `script.js`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. Через некоторое время GitHub покажет ссылку на опубликованный сайт.

## Сохранения и аккаунты
Игра сохраняет локальные аккаунты и прогресс в `localStorage` браузера. Эти данные не синхронизируются между устройствами и браузерами. Пароли в этой версии хранятся локально в браузере без серверной защиты — не используйте реальные или важные пароли.

Сохранения совместимы с предыдущей версией игры благодаря прежним ключам `snakeNG_accounts_v1`, `snakeNG_session_v1` и `snakeNG_music_v1`.
